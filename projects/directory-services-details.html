Directory Services & Infrastructure Deployment

A lab-based deployment of Active Directory and related identity and access management services.

Active Directory lab environment

Project Overview

This project involved building a Windows Server-based directory services environment to simulate the core identity and access management capabilities used in enterprise networks. It provided practical experience with Active Directory, user administration, domain joining, and shared-resource access control.

The deployment focused on creating a centralized structure where users, computers, and groups could be managed from a single domain environment. This helped reinforce how organizations enforce authentication, authorization, and file access policies across multiple systems.

  • Deployed Active Directory Domain Services in Windows Server
  • Created users, groups, and organizational units
  • Configured domain-joined client systems and shared folder access

Implementation

Active Directory Deployment

Installed and configured Active Directory Domain Services to establish a functioning domain environment with centralized identity services.

User and Group Management

Created users, security groups, and organizational units to mirror common enterprise administration practices and role-based access control.

Client Integration

Joined Windows client machines to the domain so they could authenticate through the centralized directory services environment.

Technologies Implemented

Active Directory & Domain Services

Installed and configured AD DS on Windows Server to deliver centralized identity, authentication, and policy management for the lab environment.

DNS & DHCP

Implemented DNS zones and DHCP scopes to support domain name resolution and automated IP assignment for domain-joined systems.

File Sharing & Permissions

Built SMB file shares with coordinated share and NTFS permissions. Tested effective access control using groups, inheritance, and delegated rights.

Access Control & Permissions

Shared Resources

Configured shared folders and applied both share permissions and NTFS permissions to control who could access files and what actions they could perform.

This included testing inheritance, effective access, and group-based permission assignment to ensure access controls behaved as intended.
