Directory Services & Infrastructure Deployment

Overview · Identity Services · Resource Access

This project focused on deploying and managing Windows Server directory services to simulate centralized identity and access control in a lab environment.

What's included

  • Deployed Active Directory Domain Services in Windows Server to simulate centralized identity management.
  • Created and managed users, groups, organizational units, and domain-joined Windows client systems.
  • Configured shared folders using NTFS and share permissions to control access based on group membership and inheritance.
